Grid Scanner By ArupD v5.46

Deterministic label-template scanner.
- Type 1: RunSheet = top linear barcode; Sort Code = right-side bold 4-char code (example TG1K).
- Type 2: RunSheet = center QR; Sort Code = center bold 4-char code (example MSA1).
- Date/time and unrelated label text are never used as RunSheet ID.
- Every new capture clears previous scan values.
- Grid No comes only from GridMaster.
- Label recognition has a hard ~4.8 second processing budget.
