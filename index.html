Sorting & Putting

ONLINE

Sorting

1. Scan Label

Label-এর ছবি তুলুন। Barcode থেকে RunSheet ID এবং OCR থেকে Sort Code/Grid No পড়ার চেষ্টা করবে।

2. Grid Master-এর Grid Barcode Scan

Grid No যদি A1 হয়, barcode-এর value অবশ্যই A1 হতে হবে। অন্য barcode হলে reject করবে।

Putting

1. Scan Label

Putting-এর label-ও একইভাবে RunSheet ID, Sort Code এবং Grid No বের করবে।

2. Grid Master-এর Grid Barcode Scan

Grid Master থেকে Grid No আসার পরেই camera খুলবে। Barcode value Grid No-এর সঙ্গে exact match না হলে Putting হবে না।
